## How the pieces fit

![Repository architecture](/architecture.svg)

The catalog stays small and explicit: skill sources are human-readable Markdown, `vd build` emits agent-specific surfaces, GitHub Actions validates the catalog, and Release Please keeps the version synchronized across `version.txt`, `skills.toml`, and the Claude plugin manifests.

Read next: [Install](/install/), [Skill Catalog](/skills/), [System Architecture](/system-architecture/).
