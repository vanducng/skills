# gws account: example

Copy to `~/.config/vd/gws-accounts/<alias>.gws-account.md`. Keep the local copy outside Git.

## Connection

- Email: `user@example.com`
- Domain: `example.com`
- Config dir: `~/.config/vd/gws/<alias>`
- Timezone: `Asia/Ho_Chi_Minh`
- Workspace admin: no

## Defaults

- Use for: which requests should route to this account (work vs personal, which domain)
- Notes: org session policies, scope restrictions, anything that affects auth or routing
