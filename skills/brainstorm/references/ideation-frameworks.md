# Ideation frameworks

Reach for one when the seven Phase-2 lenses aren't producing genuinely different shapes. Each is tagged with what it's best for - don't run all of them, pick the one that fits the decision.

## SCAMPER - transform an existing thing

Substitute · Combine · Adapt · Modify (magnify/minify) · Put to another use · Eliminate · Reverse. Run the current approach through each verb to force a variant. **Best for:** improving or reworking something that already exists, where a clean-sheet option isn't on the table.

## How-Might-We (HMW) - reframe the problem as opportunities

Restate the problem as several "How might we …?" questions at different altitudes. "Checkout is slow" → *HMW remove steps from checkout? HMW make waiting feel faster? HMW let users check out before they finish browsing?* Each HMW seeds a different option family. **Best for:** the problem is vague or emotionally charged and the framing itself is the hard part.

## Jobs To Be Done (JTBD) - design around the underlying job

"People don't want a quarter-inch drill, they want a quarter-inch hole." Ask what *job* the user is hiring this for; design options for the job, not the feature requested. Directly operationalizes the Phase-1 want-vs-should-want probe. **Best for:** feature requests that smell like a guessed solution to an unstated need.

## Pre-mortem - diverge by failure

Imagine it's 12 months out and the chosen approach failed badly. Write the post-mortem *now* - what killed it? Each distinct failure story implies an option that avoids that failure. Pairs with Phase 3's dealbreaker column. **Best for:** low-reversibility decisions where the cost of the wrong call is high.

## First-principles - strip to fundamentals

List what's actually, physically/logically required, discard every inherited assumption, rebuild from the irreducible constraints. **Best for:** a space crusted with "that's how it's always done" where the conventional options all rhyme.

> These are tools, not a checklist. One well-chosen framework beats running five. If the seven default lenses already produced three genuinely divergent options, you don't need this file.
