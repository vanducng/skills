# Chart rules

Pick the chart from the question, then check it against the rules.

| Question type | Chart |
|---|---|
| How much now, against a target | A single number (KPI tile) with the target and the change |
| Change over time | Line (many points) or columns (few periods) |
| Compare categories | Horizontal bars, sorted by value |
| Part of a whole | Stacked bar, or a pie of five slices or fewer |
| Distribution | Histogram or box plot |
| Relationship between two measures | Scatter |
| Exact values to look up | Table |

## Rules

- **No dual axes.** Two measures with different units get two charts.
- **No 3D,** no shadows or perspective.
- **Bars and columns start at zero.** A line may start elsewhere; say so on the axis.
- **No pie with more than five slices.** Use sorted bars.
- **Colour-blind-safe palette:** categorical colours chosen from a colour-blind-safe set, checked with a simulator, with enough contrast on light and dark backgrounds.
- **Never colour alone:** a label, a pattern or the position carries the meaning too.
- **Label the axes and units;** the title states the question the chart answers.
- **One question per chart,** and the time-to-read budget on the sheet decides how many charts fit on the first screen.
