# Classifying by actionability

## Projects

A project is a series of tasks toward one goal, with a deadline or a rough timeframe.

- It has a concrete outcome, so "done" can be checked.
- It takes focused effort over days to months.
- Something is moving on it this week or this month.

If it has no goal and no timeframe, it is not a project. A project that exists only as an intention is an idea. Keep it on its Area, or as a Resource, until work starts.

**Promote actionable units out of Areas.** Almost every Area contains one or two time-bound initiatives. Give each one its own Project so it stays visible, and keep the Area for the steady-state responsibility. For example:

- "2026 tax filing", not inside Finances;
- "Onboard the new hire", not inside Direct reports;
- "Q3 board report", not inside Reporting.

Every project serves an Area, but it is not a child of the Area. Both are top-level items, related by a link.

## Areas

An area is a sphere of activity with a standard to maintain over time.

- It never finishes. You keep it at an acceptable level.
- Neglect has consequences.
- It is part of a role or an identity: health, finances, a product someone owns, a client relationship, direct reports.

Write the standard down in one line, for example "invoices out by the 5th, hours logged daily". That line is how a review tells whether the Area is healthy.

Recurring work with no end (a weekly report, an on-call rotation) is a routine of its Area, not a Project.

## Resources

A resource is a topic of interest or usefulness, with no responsibility attached. It includes reference collections: templates, snippets, playbooks, notes on a technique, decisions that bind several Areas.

The same subject can be an Area for one person and a Resource for another. Design is an Area for a designer and a Resource for a marketer.

Areas are private by default. Resources can be shared.

## Archives

Archives hold what is inactive from the other three:

- finished or cancelled Projects;
- Areas no longer held;
- Resources no longer wanted.

Archives are a store of past work that can be reactivated, so move items there rather than deleting them. When an Area is archived, keep a pointer to where its still-true facts went.

## Tie-breaks and edge cases

| Situation | Rule |
|---|---|
| Could be a Project or an Area | Project, if it has a goal and a timeframe. Otherwise Area. |
| Could be an Area or a Resource | Area. Ask "would something suffer if this were neglected?" |
| Relevant to a Project and its Area | The Project while it is active. Promote still-true facts to the Area when the Project closes. |
| An item you cannot read | Ask. Describe it and offer 2-3 placements. |
| A screenshot or image | Never auto-archive. Work out what it shows and which project it serves, or ask. |
| Too many active Projects (25 or more) | Look for Areas in disguise, and for projects to cancel, defer, delegate or shrink. |

## How items move

| From | To | When |
|---|---|---|
| Project | Area | the outcome becomes ongoing upkeep (a training plan turns into a routine) |
| Area | Project | a specific push starts inside the responsibility |
| Area | Resource | material turns out to be useful to others |
| Resource | Area | an interest becomes a commitment |
| Any | Archives | done, handed off, or no longer interesting |
| Archives | Project | past work is revived for a new effort |

Moving between buckets is the system working, not a sign the first placement was wrong. Associate an item with a new home in one of four ways:

- move the single item;
- move its whole group;
- link it, keeping the original in place;
- tag it.

Never duplicate it.

## Building the project list

1. **List.** Start from what is worrying you, what is taking more bandwidth than it deserves, and what is not making steady progress.
2. **Add a goal** to each, written as what done looks like. The name stays a short label.
3. **Add a deadline or timeframe.**
4. **Order** by what needs attention this week.
5. **Reevaluate:**
   - which goals have no project (dreams)?
   - which projects have no goal (hobbies)?
   - what can be cancelled, postponed, delegated or reduced?
